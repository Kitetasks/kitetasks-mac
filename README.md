# KiteTasks for Mac — direct download

Downloads and the Sparkle update feed for the direct-download build of KiteTasks for Mac
(`com.kitetasks.mac`). The app is also on the Mac App Store.

- **Download:** the latest DMG is attached to the newest [release](../../releases/latest).
- **`appcast.xml`:** the Sparkle feed installed copies check for updates. It is written by the
  release script; do not edit it by hand.

Every build is signed with Developer ID, notarized by Apple, and signed for Sparkle with EdDSA.
